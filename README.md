# Тайвань · роудбук

Велопоход по Тайваню во второй половине октября: замкнутое кольцо из Тайбэя, без повторных участков.

**[Открыть роудбук →](https://ykrivochurov.github.io/taiwan-roadbook/)**

|---|---|

| Короткий этап | 72 км |

## Что внутри

- Схема острова с ниткой маршрута и точками этапов
- 11 этапов с профилями высот, раскрашенными по крутизне (до 4% / 4–8% / свыше 8%)
- Протокол тайфуна: как читать предупреждения CWA и где нельзя оказаться в момент шторма
- Таблица закрытых и ограниченных дорог с объяснением, почему их нет в маршруте
- Инструменты: базы по подъёмам с GPX, реалтайм-статус шоссе, правила провоза велосипеда в поездах

## Ключевые ограничения маршрута

- **台8 Гугуань — Лишань** закрыто бессрочно после землетрясения и тайфуна Mindulle
- **Тароко** работает по пропускному расписанию, пять окон в день — для велосипеда не годится
- **Су-Хуа** запрещено для велосипедов в тоннелях, единственный участок маршрута на поезде
- **台21 Татацзя** закрывается воротами в 17:30 ежедневно

## Перед выездом

Статус дорог меняется после каждого дождя. Утром каждого горного дня проверять
[168.thb.gov.tw](https://168.thb.gov.tw/thb168) (Disaster Info.) и
[cwa.gov.tw](https://www.cwa.gov.tw/) на тайфунные предупреждения.
